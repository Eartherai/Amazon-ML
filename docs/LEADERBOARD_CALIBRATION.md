# Leaderboard calibration

SUB-001 is the first early-calibration submission. It is a frozen 51-feature LightGBM model trained on the currently materialized natural 20,000-entity sample; full-training retrieval is a separate active experiment. The local nested out-of-fold macro F0.5 is 0.9318965293, precision 0.9815828194, recall 0.8559380676. The full-pool development candidate link recall is 0.9666263011. These numbers are from known-country training and do not forecast public or private leaderboard performance, especially for unseen France.

The user-observed leaderboard reference is 0.964733. It is context, not a threshold or architecture selection target. Fold 4 remains closed during SUB-001. The submission threshold is frozen at 0.83, the median of the three nested out-of-fold outer thresholds 0.83, 0.79 and 0.83. No leaderboard result has been obtained for SUB-001 yet.

The final test candidate set is the union of same-country name and address char-3 retrieval top 100 each, searched against all provided S2/S3 test records. Every candidate in `candidate_pairs.tsv` is scored by the final model, and every predicted match must be included in that candidate list. Full-test inference is active on the Mac.
